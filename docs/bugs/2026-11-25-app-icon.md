# 应用图标与桌面名称修复（0.2.7）

设置中的两个图标原先共用同一个 SVG，Linux 桥接在保存后提前返回，未发送图标变更事件，也没有更新 GTK 图标或桌面菜单入口。Python 模块启动还缺少明确的 GTK 应用名称和程序标识，桌面可能显示 `__main__.py`。

改为两份独立绘制的 SVG；保存时先应用 GTK 图标与当前用户的 desktop 入口，再持久化，失败回滚。桥接发送既有变更事件，立即刷新侧栏及设置页。启动恢复选项；安装包包含两份图标。GTK 显式设置应用名称「无线麦 Ubuntu 版」、程序标识 `sayall-linux` 及窗口类，与 desktop 入口一致。

验证：后端 38 项测试通过；前端 725 项通过、13 项跳过。实际 GTK/WebKit 窗口点击「几何鸭」，确认两处图片立即改变、窗口图标像素改变、desktop Icon 和保存配置一致，并能正常退出。测试使用独立配置目录，未改动用户按键映射或语音工具设置。
